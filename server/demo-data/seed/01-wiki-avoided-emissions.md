# 避免排放算法（減碳計算模型）

> 好物輪轉團隊 wiki · 最後更新 2026-03-02 · 維護人：林小樹

好物輪轉是霧橋市的物資交換平台：居民把用不到的物品刊登出來，由其他居民免費領走。每完成一筆交換，平台就估算這次交換「避免」了多少碳排放，顯示在交換完成頁與每月減碳報表上。

## 公式

每筆交換的避免排放量 A（單位 kgCO2e）：

```
A = W × EF × R
```

- **W**：物品重量（kg）。由刊登者在刊登表單手動填寫。
- **EF**：該物品類別的新品生產排放係數（kgCO2e/kg），見下表。
- **R**：取代率，指領走二手物品的人因此不再購買新品的比例。目前所有類別統一使用 **0.7**。

範例：一張 12 kg 的木椅，A = 12 × 1.8 × 0.7 = **15.12 kgCO2e**。

## 類別排放係數（EF）

| 類別       | EF（kgCO2e/kg） |
| ---------- | --------------- |
| 木製家具   | 1.8             |
| 衣物與布料 | 15.0            |
| 小家電     | 6.5             |
| 書籍與紙類 | 1.2             |
| 兒童用品   | 4.0             |

係數取自虛構的「霧橋市循環經濟辦公室 2025 年版係數表」，每年一月檢查一次是否有新版。

## 每月減碳報表

每月 5 日以前，由張小石把上個月的交換與避免排放量匯出成 CSV，寄給霧橋市循環經濟辦公室，作為「社區減碳試辦計畫」的成果資料。試辦計畫期間為 2026-01 至 2026-06。

## 已知限制

- R 是全類別統一值，沒有區分家具和衣物。
- 二手物品通常比新品用得短，公式目前沒有考慮這點。
- 沒有扣除取件時的運送排放。
