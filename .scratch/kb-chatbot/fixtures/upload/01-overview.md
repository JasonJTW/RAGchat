# 01 總覽：Megaweaving 是什麼

_最後更新：2026-11-03_

「Megaweaving」一詞在公開資料裡指三件彼此相連的事，依時間先後是：

```
理念（2007 提出）──► 實踐（2008 起：教學/方案/工作營/創作/策展）──► FB 社團（2015 起）──► megaweaving.net 平台（2025 起開發）
```

## 1. 作為「理念」：大量交織 Mega-weave

- **提出者**：蕭有志（Yu-Chih Hsiao），實踐大學建築設計學系副教授。
- **出處**：他在 Cranbrook Academy of Art 的建築碩士畢業製作／論文作品集標題。〔🅐 [About Megaweave](https://yuchih-hsiao.net/About-Megaweave)；🅐 [看守台灣〈大量交織〉2010](https://yuchih-hsiao.net/8526217)〕
- **英文定義**（原文）："The concept emphasizes on cultural diversity, resource maximum, waste=foods, crossing projects, and do-it-yourself urbanism."〔🅐 [About Megaweave](https://yuchih-hsiao.net/About-Megaweave)〕
- **中文定義**（原文）：「『大量交織』關注環境與文化議題，強調文化多樣性，關注人與人之間、群體與群體之間的合作與互動，同時也強調藉由資源傳輸與轉化將資源效益最大化，使過剩成為養份 (Waste = Food)。」〔🅐 About Megaweave；🅑 [HackMD 社團清單轉錄](https://hackmd.io/@openlabtaipei/SkT8ZK2OI)〕
- **理論基礎**：以複雜學（complexity）為基礎，把整個社會視為一個複雜系統。〔🅐 [Flickr「大量交織之搖籃書房」相簿說明](https://www.flickr.com/photos/magaweaving/albums/72157624921601344/)〕
- **五個關鍵字**：cultural diversity（文化多樣性）、resource maximum（資源最大化）、waste = food（過剩成為養份）、crossing projects（跨方案資源整合）、do-it-yourself urbanism（自己動手的都市主義）。

詳見 [02-origin-philosophy.md](02-origin-philosophy.md)。

## 2. 作為「實踐方法」：四條路線並行

蕭有志 2008 年返台後，讓**教學、設計方案、非營利工作營、藝術創作**四條路線同時進行、彼此交錯，並把資源交換模式嫁接到一般資本市場的方案運作中，讓不少方案「在極低限的預算中卻也能轉化出豐碩的成果」。〔🅐 [About Megaweave](https://yuchih-hsiao.net/About-Megaweave)〕

代表案例：

- 一百元的大直社區改造計畫（2008–2012）
- 搖籃書房（2009）
- 旅行的大洋蔥（2009/2010–2019）
- 自由小屋（2011–2023）
- 都市耕讀小屋（2013–2016）
- 旅梯計畫（2017–2023）
- 樹屋三連作（2018）
- Nest（2007 Cranbrook 原作；2025 Santa Clara University 重製）

詳見 [05-projects-and-practice.md](05-projects-and-practice.md)。

## 3. 作為「社群」：Facebook 社團「大量交織 Megaweaving」

- 社團網址：https://www.facebook.com/groups/1596603907320118/
- 蕭有志自 **2015 年**起經營，倡議資源整合與閒置資源轉換。〔🅐 [BIO](https://yuchih-hsiao.net/BIO)〕
- 成員數（依時間）：**8,000+**（個人網站簡歷，約 2023）→ **約 11k**（GitHub README，2025–2026）→ **12,000+**（Substack，2026-10-02）。
- 使用者評價（2024-09，Threads）：「裡面都是惜物的人或有需求的人 我個人覺得社團風氣非常好」〔🅒〕

詳見 [06-facebook-community.md](06-facebook-community.md)。

## 4. 作為「產品」：megaweaving.net

- 標語：「megaweaving 大量交織｜免費物品交換與共享平台」／英文 "free item exchange and sharing"。〔🅐 [megaweaving.net](https://megaweaving.net/)〕
- 核心機制：**Share**（我有，拿去）／**Wish**（我在找）→ 另一方發起 **Weave**（一次交換）。〔🅐 [GitHub README](https://github.com/JasonJTW/megaweave)〕
- 交換本身不涉及金錢，唯一付費路徑是選用的 Lalamove 快遞（ECPay 付款）。
- 「地球公物 / Commons」標示為即將推出。
- 原始碼庫建立於 **2025-06-21**，第一個 commit 是 2025-06-23，截至 2026-10-30 仍持續開發（648 commits）。

詳見 [07-megaweaving-net-platform.md](07-megaweaving-net-platform.md)。
